# Code of Conduct

## Our standard

This is a small project. The bar is simple:

- **Argue with the work, not the person.** Disagreement about a design, a number or
  a paper is welcome and expected — especially about a number, since the whole point
  of this project is that claims get checked.
- **Assume competence.** Someone who asks a basic question is not wasting your time;
  someone who disagrees is not automatically hostile.
- **No harassment, no bigotry, no personal attacks.** Not in issues, not in pull
  requests, not in commit messages.
- **No invented evidence.** Presenting a made-up benchmark, a fabricated citation or
  a screenshot of output that never ran is the one thing this project treats as
  disqualifying rather than merely wrong. It is the failure mode the tool exists to
  catch.

## Scope

Issues, pull requests, commit messages, discussions, and any space where you are
representing this project.

## Reporting

Report a problem privately through the repository's **Security → Advisories →
Report a vulnerability** channel, or by contacting the maintainer directly on the
[Nous Research Discord](https://discord.gg/nousresearch) as **LeMultiFox**. Reports
are read by the maintainer and kept confidential.

## Enforcement

The maintainer may edit or delete comments, close threads, or block accounts. There
is no committee and no appeals process — the response to a report will say what
happened and why, and that is the end of it.

## Attribution

This document is written for this project rather than adopted verbatim from the
Contributor Covenant, because a two-line policy that people read beats a
four-thousand-word one they scroll past. The Contributor Covenant
(https://www.contributor-covenant.org, CC BY 4.0) is the standard most projects
should use; this one is deliberately shorter.
